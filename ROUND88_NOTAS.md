# Round88 - Agrupamento do seletor "Acessar como"

Ajuste visual no seletor de simulação de visão do admin.

## O que mudou

O dropdown agora fica dividido em:

1. Minha visão
2. Pessoas da equipe
3. Usuários clientes

Foram adicionados separadores visuais dentro do select para facilitar a leitura quando houver muitos usuários.

## Arquivos alterados

- src/main.jsx
- dist/

## Deploy

Como é alteração apenas de front-end, basta fazer commit/push para o GitHub e aguardar o Cloudflare Pages publicar o novo deploy.
Não precisa deployar Edge Functions no Supabase.
